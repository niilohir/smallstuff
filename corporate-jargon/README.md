# Corporate Jargon Translator

**inJargonator** — Plain English → LinkedIn. Say less. Mean nothing. Sound important.

A rule-based translator that turns everyday phrases into premium corporate jargon. No API, no build step, no internet connection needed.

## Try it online

👉 **https://niilohir.github.io/smallstuff/corporate-jargon/**

## Run it locally

1. Download the repo: on the [repo page](https://github.com/niilohir/smallstuff), click the green **Code** button → **Download ZIP**, then unzip it.
   (Or, with git: `git clone https://github.com/niilohir/smallstuff.git`)
2. Open the `corporate-jargon` folder.
3. Double-click `index.html` — it opens in your browser and works offline.

## Files

- `index.html` — categories and random translations
- `translator.html` — live translator for any sentence
- `category.html` — phrases for one category
- `data.js` — the phrase dictionary
- `translator-engine.js` — the rule-based translation engine
- `style.css` — styles
